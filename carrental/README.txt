CAR RENTAL - One-to-Many (ONE CUSTOMER has MANY RENTALS) with PDO

SETUP
1. Open XAMPP Control Panel and START Apache and MySQL.
2. Put this folder named "carrental" inside C:\xampp\htdocs\
   Final path: C:\xampp\htdocs\carrental\index.php
3. Open: http://localhost/carrental/index.php

The database (carrental_db) and tables (customers, rentals) are created automatically.
Do NOT import any .php file into phpMyAdmin.
